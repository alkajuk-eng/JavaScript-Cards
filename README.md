## 📖 About the Project

**JavaScript Cards** is a responsive front-end web application created using **HTML, CSS and Vanilla JavaScript**.

The project allows users to create, save and manage entries directly in the browser.

Data is stored using the browser's **Local Storage**, so the information remains available after refreshing the page.

This project was created as a practical exercise to develop my skills in:

* JavaScript
* DOM manipulation
* Event handling
* Local Storage
* Form processing
* Responsive web design
* Git and GitHub

---

## ✨ Features

### 📝 Create Entries

Users can create new entries through a dedicated form.

### 💾 Local Storage

Entries are saved directly in the browser using:

```javascript
localStorage
```

This means the data remains available after refreshing the page.

### 🗂️ Vault

The **Vault** page displays the saved entries and allows users to manage their stored information.

### 📱 Responsive Design

The application is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

### ⚡ Dynamic JavaScript

The interface is dynamically updated using JavaScript without requiring a page reload for every action.
